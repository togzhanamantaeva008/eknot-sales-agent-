# Техническое задание: AI-агент продаж

## 1. Цель
Создать AI-агента, который общается с клиентами, подбирает товары/услуги (умный дом, онлайн-голосование e-KNOT) и ведёт клиента от первого контакта к заявке на демо или покупке.

## 2. Задачи
1. Автоматизировать первичное общение с клиентом (ответы на типовые вопросы 24/7).
2. Выявлять потребность и подбирать позиции из каталога.
3. Находить лидов в чатах и готовить портрет клиента.
4. Отправлять персональное первое сообщение (холодный контакт).
5. Фиксировать диалоги для анализа руководителем.

## 3. Пользователи
- **Клиент** — пишет в Telegram/WhatsApp.
- **Менеджер/руководитель** — тестирует бота (пилот), читает логи, получает лидов.

## 4. Функциональные требования
| № | Функция | Описание | Приоритет |
|---|---------|----------|-----------|
| F1 | Приветствие и /start | Бот приветствует, запускает диалог | Высокий |
| F2 | Ответы на вопросы | Gemini отвечает по правилам из системного промпта | Высокий |
| F3 | Подбор товаров | По ключевым словам из каталога предлагает до 3 позиций | Высокий |
| F4 | Обработка возражений | Цена, законность, сложность — спокойный ответ и уточняющий вопрос | Высокий |
| F5 | Сброс диалога /reset | Начать заново | Средний |
| F6 | Воронка лидов | Анализ чата → лид (score) → портрет → холодное сообщение | Высокий |
| F7 | Логирование | Сохранение диалога пилота в файл | Средний |
| F8 | Подключение WhatsApp | Через WhatsApp Cloud API (после пилота) | Низкий |

## 5. Нефункциональные требования
- Язык: русский. Ответ до 10 секунд. При ошибке Gemini — вежливое сообщение.
- Ключи (Gemini, Telegram) только в `.env`, не в репозитории.
- Бот не выдумывает цены: если не знает — «уточню».

## 6. Архитектура
Клиент (Telegram) → `bot/telegram_bot.py` → подбор из `bot/catalog.py` → Gemini (`prompts.py`) → ответ.
Воронка лидов: `funnel.py` (чаты `data/chats.json` → `results.json`).

## 7. Технологии
Python 3, google-generativeai (Gemini), python-telegram-bot, Google Cloud (сервер).

## 8. Этапы
- Спринт 1: ТЗ, структура бота, сценарии, прототип.
- Спринт 2: воронка лидов, пилот с руководителем, сервер и Gemini на Google Cloud, затем WhatsApp.
- Спринт 3: внедрение и донастройка.
- Спринт 4: анализ результатов, масштабирование.

## 9. Критерии приёмки
- Бот проходит сценарии из `docs/scenarios.md`.
- Воронка находит лидов в тестовых чатах (см. `docs/test_log.md`).
- Пилот с руководителем проведён, диалог сохранён.
